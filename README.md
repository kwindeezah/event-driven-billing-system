# Event-Driven Billing System

## Overview
A backend system designed to handle subscriptions, payments, and analytics using a modular monolith architecture.

## Features
- Subscription lifecycle management
- Payment processing
- Retry mechanism for failed payments
- Event-driven architecture
- Analytics tracking

## Tech Stack
- Laravel (PHP)
- PostgreSQL
- Redis
- Kafka
- Docker

## Architecture
- Modular Monolith
- Domain-driven structure
- Service + Action pattern
- Event-based communication
